Cara menghubungkan GPT

Gunakan backend.

Folder netlify/functions dan api sudah disiapkan sebagai contoh backend. Simpan OPENAI_API_KEY sebagai environment variable di hosting serverless Anda.

Jangan taruh API key di frontend.

Website GitHub Pages bersifat publik. Jika API key dimasukkan ke JavaScript frontend, pengunjung dapat melihat dan menyalahgunakannya.
